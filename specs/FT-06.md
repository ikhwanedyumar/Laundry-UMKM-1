# FT-06 WhatsApp Deep Link Button

Sumber PRD: Bagian 5 (BL-03), Bagian 6 (FT-06), Bagian 7 (Format Template WhatsApp), Bagian 8 (AC-04), Bagian 9 (TC-05)

## Tujuan
Pengguna dapat menekan satu tombol untuk memvalidasi pesanan dan membuka obrolan WhatsApp toko berisi rincian pesanan terformat rapi.

## Alur
1. Pengguna menekan tombol **Kirim ke WhatsApp**.
2. Sistem memvalidasi berat (FT-02), nama pemesan, dan alamat penjemputan kondisional (FT-05).
3. Jika ada kolom tidak valid, sistem menampilkan pesan error di bawah kolom terkait dan memindahkan fokus ke kolom error pertama (urutan: berat -> nama -> alamat).
4. Jika seluruh data valid, sistem menyusun pesan sesuai template PRD, melakukan URL-encoding dengan `encodeURIComponent`, dan membuka tautan `https://wa.me/<STORE_WA_NUMBER>?text=<ENCODED_MESSAGE>` di tab baru (`target="_blank" rel="noopener"`).

## Data
- `STORE_INFO.whatsappNumber` (`'6281234567890'`)
- `WHATSAPP_BASE_URL` (`'https://wa.me/'`)
- Template pesan resmi PRD Bagian 7

## Aturan dan rumus
- Template wajib (utuh dari PRD Bagian 7):
```
Halo Admin Laundry, saya ingin memesan layanan laundry dengan rincian berikut:

*Nama:* [Nama Pelanggan]
*Layanan Utama:* [Cuci Lipat / Cuci Setrika / Cuci Setrika Ekspres]
*Estimasi Berat:* [X] kg (Berat Ditagih: [Y] kg)
*Layanan Tambahan:*
- Antar-Jemput: [Ya (+Rp 10.000) / Tidak]
- Pewangi Premium: [Ya (+Rp Z.000) / Tidak]

*Alamat Penjemputan:* [Alamat Lengkap / "Antar Sendiri ke Toko"]
*Catatan Khusus:* [Catatan khusus atau "-"]

*Estimasi Total Biaya:* *Rp [Total]*

_(Catatan: Total di atas adalah estimasi awal. Berat pasti akan ditimbang kembali saat pakaian diterima oleh kasir/kurir laundry)._

Mohon konfirmasi pesanan dan ketersediaan jadwalnya. Terima kasih!
```
- Nilai berat `[X]` dan `[Y]` memakai format desimal koma tanpa nol di belakang (misal `4,5` dan `3`).
- Nilai uang di pesan memakai format Rupiah ber-spasi (misal `Rp 61.000`, `+Rp 10.000`, `+Rp 6.000`).
- Seluruh isi pesan di-encode memakai `encodeURIComponent`.
- Pembukaan tautan menggunakan elemen/navigasi aman dengan `noopener` tanpa `window.alert`.

## Input dan validasi
- Menggunakan hasil validasi gabungan berat, nama, dan alamat penjemputan.

## Tampilan dan teks
- Label tombol: `Kirim ke WhatsApp` (sesuai AC-04 dan batas panjang 1-3 kata).
- Tinggi tombol minimal `44 px`, warna `bg-emerald-700 hover:bg-emerald-800 text-white`.
- Saat tautan dibuka, tampil konfirmasi singkat yang tidak mengganggu (inline status) disertai tautan cadangan jika pop-up diblokir browser.

## Kasus uji
| ID | Input | Hasil yang diharapkan | Sumber |
| :--- | :--- | :--- | :--- |
| AC-04 | Form lengkap valid | Membuka `https://wa.me/6281234567890?text=...` dengan rincian sama persis dengan layar | PRD AC-04 |
| TC-05 | Catatan: `"Baju dinas & sutra, jangan dicampur!"` | Karakter `&` ter-encode aman (`%26`) dan isi pesan utuh saat di-decode tanpa memutus parameter `text` | PRD TC-05 |
| FT06-B1 | Antar-Jemput tidak dicentang, Catatan kosong | Alamat tertulis `Antar Sendiri ke Toko`, Catatan tertulis `-` | PRD Bagian 7 |
